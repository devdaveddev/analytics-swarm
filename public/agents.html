Agent interface

Workflow editor

Drag an agent by its handle to change the order it runs in, or use the arrow buttons. Wires show results passing from one agent to the next. The order is checked as you edit, because some agents need another agent's output first.

    The canvas scrolls sideways on wide screens. Hold an agent near the left or right edge while dragging to scroll.

    Add an agent

    Optional agents that are not in the workflow right now. An added agent is placed after the agents it needs.

    Create a custom agent

    A custom agent runs your own instructions on the analysis and adds its answer to the dashboard. Tell it what role to play, what to look at, and how to answer. It sees the KPIs, insights, sentiment, recommendations, forecast and document summaries from the agents before it, plus notes from earlier custom agents. It needs a model, so turn on Ollama or add a key on the API Key page.

    How ordering works

    • Custom agents read the analysis, so they must come after Parser and Refiner and before the Visualizer.
    • Required agents cannot be removed: Parser, Analyzer, Refiner, Consultant and Visualizer.
    • Needs means the agent reads another agent's output, so that agent must come first.
    • An amber note means the order is allowed but the agent will not use an output that has not been produced yet.
    • The Visualizer always runs last, because it builds the dashboard from everything before it.
